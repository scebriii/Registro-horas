# Mis Horas

Aplicación web para registrar horas trabajadas y calcular el pago mensual automáticamente.

## Qué hace

- Registra horas por día desde un calendario interactivo
- Calcula el importe a cobrar en tiempo real según tarifa por hora
- Detecta y marca horas extra (por encima del contrato semanal)
- Muestra resumen semanal con barras visuales
- Funciona en móvil y escritorio
